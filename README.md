# Tuneflow 🎵

A beautiful, modern music streaming web application that brings you an extensive collection of Hindi songs with an elegant glass-morphism interface and seamless user experience.

## ✨ Features

- **Extensive Music Library**: 165+ Hindi songs spanning various genres and eras
- **Modern UI/UX**: Glass-morphism design with animated backgrounds
- **Smart Search**: Quick song search functionality
- **Responsive Design**: Works seamlessly across all devices
- **Integrated Tools**: Quick access to ChatGPT, Perplexity, Gemini, and GitHub
- **Real-time Clock**: Elegant liquid glass clock display
- **Brightness Control**: Adjustable video background brightness
- **Smooth Animations**: Fluid transitions and micro-interactions

## 🎵 Music Collection

The application includes a diverse collection of Hindi songs, featuring:

- **Classic Hits**: Timeless melodies from legendary artists

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- Local web server (optional, for development)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/tuneflow.git
cd tuneflow
```

2. Serve the application:
```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx serve .

# Or simply open index.html in your browser
```

3. Open your browser and navigate to `http://localhost:8000`

## 🔧 Customization

### Adding New Songs

1. Place your MP3 files in the `songs/` directory
2. Update the song list in `script.js`
3. Ensure proper naming conventions for consistency

### Modifying the UI

- Edit `css/index.css` for styling changes
- Modify `index.html` for structural changes
- Update `script.js` for behavioral modifications

### Changing Background

1. Replace `media/bg.mp4` with your video file
2. Adjust the overlay opacity in the CSS
3. Update the brightness control range if needed
